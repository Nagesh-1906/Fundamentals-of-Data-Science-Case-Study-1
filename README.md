### Overview
This project performs market basket analysis and transaction segmentation on retail data:
- Preprocessing raw transaction baskets using binary vectorization (`MultiLabelBinarizer`).
- Exploratory data analysis on product frequency and order sizes.
- Dimensionality reduction via Principal Component Analysis (PCA).
- Implementation and benchmarking of 4 unsupervised clustering algorithms: K-Means, Agglomerative Hierarchical, DBSCAN, and Spectral Clustering.
- Validation using Silhouette Coefficient and Davies–Bouldin Index.
